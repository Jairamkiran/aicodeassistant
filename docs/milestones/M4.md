# Milestone 4 — Indexing Worker & Saga

**Objective.** Turn an imported repository into searchable vectors: the
`indexer-worker` consumes the import event and runs a compensating saga —
clone → parse → chunk → embed → upsert into pgvector — then reports completion so
the repository becomes READY. This is the distributed-systems centrepiece.

## Scope decisions (L6 review)

- **Repo locking → atomic DB status-claim, not Redisson** (ADR-0009): avoids the
  lock-TTL-vs-multi-minute-clone double-processing hazard. Redisson stays
  deferred.
- **Chunking → line-based windowing, not AST** (ADR-0010): what production RAG
  ships first; AST deferred until M5 retrieval metrics justify it.
- **Embedding → concrete Ollama client, no provider abstraction** (integration
  directive): a port waits for a second provider (M6).
- **Full pipeline through pgvector** — M4 ends in real embedded vectors; querying
  them is M5.

## Flow & state machine

```
Kafka: repository.import-requested
        │
        ▼  (indexer-worker)
   ensure IndexJob(REGISTERED)
        │
   claim: UPDATE ... status=CLAIMED WHERE status=REGISTERED   ── 0 rows ─▶ NOT_CLAIMED (no-op)
        │ 1 row
        ▼
   deleteByRepository (idempotency)
        ▼
   CLONING  ──JGit shallow clone (temp dir)──────────────────────┐
        ▼                                                          │ any failure
   PARSING  ──chunker: line windows + overlap, skip binary/large──┤
        ▼                                                          ▼
   EMBEDDING ──Ollama /api/embed (batch, resilient)──▶       COMPENSATE:
        ▼                                                     delete vectors,
   UPSERTING ──pgvector code_chunks (batch INSERT)──▶         markFailed(reason),
        ▼                                                     publish RepositoryIndexingFailed
   INDEXED  ──publish RepositoryIndexed(chunkCount)
        │                                                     (clone dir always closed)
        ▼  Kafka: repository.indexed / repository.indexing-failed
   (app) repository context → Repository READY / FAILED
```

## Module ownership & boundaries

- **`indexing`** (worker-owned): the saga, `IndexJob` aggregate + its own
  `index_jobs` table, `Chunker`, ports (`RepositoryCloner`, `IndexJobStore`),
  JGit + Kafka adapters. Depends only on `ai :: embedding` and
  `retrieval :: chunk` (explicit allowed deps, modularity-verified). It **never
  writes another context's tables** — it emits completion events.
- **`ai`** (`embedding` named interface): concrete `OllamaEmbeddingClient`
  (RestClient, Resilience4j retry+breaker, timeouts, `ai.embedding.call` metric).
- **`retrieval`** (`chunk` named interface): `ChunkVectorStore` write side, pgvector
  via `JdbcTemplate`.
- **`repository`** (app): consumes `repository.indexed`/`indexing-failed` (local
  inbound DTOs, not indexing's types) → updates `Repository` status.

## Reliability & failure modes

| Concern | Handling |
| --- | --- |
| Exactly-once | atomic conditional-update claim (ADR-0009); duplicate delivery → NOT_CLAIMED no-op |
| Partial failure | saga compensation: delete partial vectors, mark FAILED + reason, emit failed event |
| Idempotent re-index | `deleteByRepository` before upsert; re-run does not duplicate chunks |
| Clone cleanup | `ClonedRepository` is `AutoCloseable`; temp dir deleted even on failure |
| Embedding provider down | Resilience4j retry (exp backoff) + circuit breaker; then EmbeddingException → saga compensates |
| Poison Kafka message | unparseable → logged + acked (won't block partition); processing failure → not acked → redeliver (safe via claim) |
| Worker dies mid-index | job left non-terminal; stale-job reaper is a noted follow-up |

## Database schema

- `V7__index_jobs.sql` — saga state, unique per repository, atomic-claim target.
- `V8__code_chunks.sql` — `vector(768)` embedding column + HNSW cosine index.

## Testing strategy

- **Executed, no Docker (20 tests):**
  - `IndexingSagaTest` — full happy path, not-claimed no-op, clone-failure and
    embedding-failure compensation, re-index idempotency, empty-repo — all with
    in-memory fakes for every port.
  - `ChunkerTest` — windowing/overlap, blank skip, language-by-extension, config
    validation.
  - `JGitRepositoryClonerTest` — real JGit clone of a local `file://` repo; text
    read, binary + oversized skipped, cleanup.
  - `OllamaEmbeddingClientTest` — WireMock: success mapping, 5xx/timeout/count-
    mismatch → EmbeddingException.
  - `PgVectorChunkStoreTest` — vector-literal formatting.
  - Worker context loads on H2 + embedded Kafka; stays web-business-free.
- **Authored, CI-only (Docker):** pgvector upsert IT (Testcontainers Postgres),
  Kafka consume→saga IT.
